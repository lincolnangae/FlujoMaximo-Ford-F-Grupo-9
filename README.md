# 🌐 Simulador de Flujo Máximo — Algoritmo de Ford-Fulkerson

Proyecto grupal para la visualización, experimentación y resolución de problemas de **Flujo Máximo** en redes mediante el algoritmo de **Ford-Fulkerson**.

## 🚀 Estado Actual del Proyecto (Fase 1)
- **Estructura Base HTML5/CSS3:** Panel de configuración lateral y lienzo SVG responsive.
- **Distribución de Nodos:** Generación dinámica de grafos con distribución circular (7 a 16 vértices).
- **Sistema de Alertas:** Modal interactivo para validaciones de entrada.

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript (ES6+)
- SVG (Scalable Vector Graphics)
